FFXIV Tools & Links

A running list of things I actually use. Updated whenever I find something worth keeping.

Market & Economy

  • UniversalisCross-world market board data
  • TeamcraftCrafting lists, alarms, gathering routes

Progress & Checklists

  • XIV To-DoDuty completion tracker for dungeons, raids, and trials (less useful for the dailies checklist)
  • MSQTrackerMain Scenario Quest progress tracker, kept current through Dawntrail (progress saves to your browser only; export/import to move it, no shareable link)
  • FFXIV ProgressMSQ progress tracker; stopped receiving updates after Endwalker, so use MSQTracker above for anything post-Endwalker
  • FFXIV CollectLook up and compare minions, mounts, and other collectibles you're tracking
  • Eureka TrackerEureka NM pop time tracker, the community standard
  • PAISSA DBTracks open housing plots and wards in real time, what I use to find and review options before bidding
  • Housing Plot ViewerBrowse screenshots and views for every plot so you can judge whether you'd like it without visiting in game

Venues & Nightlife

  • FFXIV VenuesDirectory and schedule of player-run venues across NA/EU data centers

Glamour

  • Eorzea CollectionVanilla (no-mod) glamour gallery. Browse and save outfits for in-game use

General & Community

  • DiscordMain way I message friends and stay in touch with the community (heavy daily use)
  • TwitchIn-game event streams and DJ sets

Guides & Reference

  • XIV ResourcesExhaustive, uncurated directory of FFXIV sites, APIs, and dev tools, for when this list doesn't have it
  • FFXIV Chocobo Colour CalculatorPlan out chocobo color breeding/feeding paths
  • Garland ToolsItem, recipe, and quest database
  • XIVStatsGeneral-purpose database with datasets you won't find elsewhere, like desynthesis results. The housing viewer for plot numbers is what I use most
  • Icy Veins: FFXIVJob guides. I use it for a default crossbar/hotbar setup when leveling a new class on controller
  • Console Games Wiki: FFXIVGeneral item and quest info, easy to figure out what or how to go get something
  • Retainer Ventures Minions GuideList of every minion obtainable from retainer exploration ventures, and which venture unlocks each one
  • FFXIV Gardening: Crossbreed DiagramsHybrid seed crossbreeding paths. I use it for Thavnair onions
  • The LodestoneOfficial news, maintenance, and lore updates

Unicode & Special Characters

  • Unicode FFXIV Symbols and More (Reddit)Community-cataloged Unicode symbols that render in FFXIV chat and names
  • Unicode Character Table (Gist)Broader Unicode reference table, linked to the FFXIV-relevant range
  • Special Characters (Lodestone Blog)Player-written Lodestone blog post listing special characters for names and chat
  • Special Chat Characters (Wiki)Wiki page listing the special characters FFXIV's chat and name fields support
